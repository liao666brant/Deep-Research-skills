# 通用网页搜索

适用于查找通用信息、新闻、产品对比和最佳实践。

## 搜索源

- Reddit（r/programming、r/webdev 及对应主题的社区），实际使用经验
- 官方文档和更新日志，产品行为和版本变化
- Hacker News，技术讨论
- Dev.to（dev.to），开发者体验和教程
- Medium（medium.com），技术分析和长文
- Discord，开源项目官方讨论频道
- X/Twitter，开发者和维护者的技术公告及讨论

## 查询策略

- 优先核对官方建议，并与社区共识交叉验证。
- 查找生产项目中的实例、实际案例、性能基准和用户体验。
- 识别常见错误用法，留意已弃用的方案和变化中的实践。
- 比较方案时说明评价标准，纳入扩展性、维护成本、学习成本和其他影响决策的取舍。
