# 学术论文搜索

适用于查找学术论文、调研算法和技术原理。

## 搜索源

- Google Scholar（scholar.google.com），综合学术搜索
- arXiv（arxiv.org），数学、物理、计算机等领域的预印本
- Hugging Face Papers（huggingface.co/papers），机器学习和 AI 热门论文
- bioRxiv（biorxiv.org），生物学和生命科学预印本
- ResearchGate（researchgate.net），论文和研究者资料
- Semantic Scholar（semanticscholar.org），学术搜索与引用信息
- ACM Digital Library 和 IEEE Xplore，计算机科学与工程论文

## 查询策略

- 优先使用 Google Scholar 及其高级搜索运算符。
- 按作者、标题、DOI、机构和发表年份搜索。用引号匹配准确标题和作者组合。
- 限定年份以查找特定时期的成果，沿相关论文和引用关系追踪代表性工作。
- 搜索 arXiv、bioRxiv 和机构知识库中的预印本，查看是否有开放获取版本和合法下载入口。
- 检查作者主页获取其他论文及 PDF，搜索相关会议论文集、期刊和研讨会论文。
- 结合影响因子、h 指数和引用次数评估来源，必要时了解资助机构与项目背景。
