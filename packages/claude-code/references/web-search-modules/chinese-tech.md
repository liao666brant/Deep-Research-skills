# 中文技术社区搜索

适用于排查中文技术问题、调研国内框架和查找社区方案。

## 搜索源

- CSDN（csdn.net），技术文章和解决方案
- 掘金（juejin.cn），开发者文章和框架讨论
- SegmentFault 思否（segmentfault.com），中文技术问答
- 知乎（zhihu.com），知识分享和讨论
- 博客园（cnblogs.com），技术博客
- 开源中国（oschina.net），开源项目和技术资讯
- V2EX（v2ex.com），开发者社区讨论
- 腾讯云和阿里云开发者社区，企业技术方案

## 查询策略

- 涉及中英文资料时，分别构造中文和英文查询。
- 使用中文技术术语及常见译法，例如「报错」「解决方案」。
- 搜索中文站点时优先使用中文关键词。
